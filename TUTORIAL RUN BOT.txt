🦕 *TUTORIAL RUN BOT DI PTERODACTYL*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 *Startup Command yang digunakan:*
```
bash start-ptero.sh
```

> _Menggunakan_ `bash start-ptero.sh` _sebagai Startup Command adalah cara yang* *tepat untuk mencegah bot crash diam-diam di panel Pterodactyl._
> _Script ini melindungi bot dengan auto-restart otomatis saat crash, auto-install dependensi, dan notifikasi Telegram — sehingga bot selalu hidup tanpa perlu dipantau manual._

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🛡️ *KENAPA PAKAI bash start-ptero.sh?*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• *🔄 Auto-Restart saat Crash*
  Bot yang crash atau exit otomatis dihidupkan kembali tanpa perlu klik Start manual di panel _(maks 10x restart, jeda 5 detik tiap restart)_

• *📦 Auto-Install Dependensi*
  Jika `node_modules` belum ada saat pertama start, script langsung jalankan `npm install` otomatis — _tidak perlu install manual_

• *📊 Laporan Harian via Telegram*
  Setiap 24 jam bot kirim laporan otomatis berisi uptime, total crash & restart, dan info memori server _(aktif jika Telegram dikonfigurasi)_

• *🔔 Notifikasi Crash & Restart*
  Setiap kali bot crash dan restart, notifikasi langsung dikirim ke Telegram dengan keterangan exit code dan waktu kejadian

• *🚫 Mencegah Bot Mati Diam-Diam*
  ~Tanpa script ini~, jika bot crash di panel Pterodactyl, bot akan diam tanpa merespons hingga kamu restart manual — _bisa berjam-jam tidak ketahuan_

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 *LANGKAH-LANGKAH*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

*1. 📁 Upload File Bot*
• Upload semua file bot ke File Manager panel Pterodactyl
• Atau clone dari repository menggunakan fitur Git/Terminal di panel

*2. ⚙️ Set Startup Command*
1. Masuk ke panel Pterodactyl
2. Pilih server bot kamu
3. Klik tab *Startup*
4. Cari kolom *Startup Command*
5. Hapus isi lama, ganti dengan:
```
bash start-ptero.sh
```
6. Klik *Save* / *Update Startup*

*3. 🔑 Set Environment Variables* _(Opsional)_
> Isi variabel berikut di tab Startup jika tersedia di panel:

• `BOT_NUMBER_PAIR`  → nomor WA bot tanpa + _(contoh: 6281234567890)_
• `BOT_SESSION_NAME` → nama sesi bebas _(contoh: hisoka)_
• `BOT_PREFIX`       → prefix command _(contoh: .)_
• `BOT_MAX_RETRIES`  → maks reconnect _(contoh: 5)_
• `BOT_LOG_MESSAGE`  → log pesan masuk _(true / false)_
• `BOT_LOGGER_LEVEL` → level log _(silent / info / debug)_

> Jika panel tidak ada kolom env, atur langsung di `config.json`

*4. ▶️ Jalankan Bot*
1. Klik tombol *Start* di panel
2. Buka tab *Console*
3. Tunggu hingga muncul output berikut:
```
▶ Wily Bot - Pterodactyl Mode
✅ Menjalankan bot dengan auto-restart...
```
4. Beberapa detik kemudian *Pairing Code* muncul di console

*5. 📱 Pairing WhatsApp*
1. Buka *WhatsApp* di HP
2. Ketuk ⋮ _(titik tiga pojok kanan atas)_
3. Pilih → *Perangkat Tertaut*
4. Pilih → *Tautkan Perangkat*
5. Pilih → *Tautkan dengan Nomor Telepon*
6. Masukkan kode pairing yang tampil di console panel

*6. 🤖 Bot Online ✅*
• Setelah pairing berhasil, bot langsung aktif
• Coba kirim command untuk memastikan bot merespons
• Jika bot crash, `start-ptero.sh` otomatis restart _(maks 10x, jeda 5 detik)_

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ *CATATAN PENTING*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ *Gunakan* → ```bash start-ptero.sh``` di kolom Startup Command
❌ ~Jangan~ → ```node index.js``` _(tidak ada auto-restart saat crash)_

• Jika `node_modules` belum ada, script otomatis jalankan `npm install` saat pertama start — _tidak perlu install manual_
• Sesi WhatsApp tersimpan di folder `sessions/` — _jangan dihapus agar tidak perlu pairing ulang_
• Notifikasi Telegram aktif jika `config.json` sudah diisi:
```
"telegram": {
  "enabled": true,
  "token": "TOKEN_BOT_TELEGRAM",
  "chatId": "CHAT_ID_KAMU"
}
```
> Bot kirim notif saat: pertama start, crash & restart, dan laporan harian otomatis setiap 24 jam _(uptime, total restart, info memori server)_

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❓ *TROUBLESHOOTING*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

*🔴 Bot tidak muncul Pairing Code?*
• Pastikan `BOT_NUMBER_PAIR` sudah diisi benar _(tanpa tanda +)_
• Cek console apakah ada pesan error merah

*🔴 Bot restart terus lebih dari 10x?*
• Buka console, lihat pesan error yang muncul
• Pastikan `config.json` tidak ada kesalahan format JSON

*🔴 Sesi hilang setelah panel restart?*
• _Normal di hosting tanpa storage persisten_
• Backup folder `sessions/` secara berkala untuk menghindari pairing ulang
