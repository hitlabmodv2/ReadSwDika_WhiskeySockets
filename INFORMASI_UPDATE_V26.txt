*1. 🐛 Konek JadiBot Baru Langsung Dianggap Expired*
_Disconnect sebentar saat proses pairing/scan QR langsung bikin sesi dihapus, padahal belum pernah konek sama sekali._
1. ~`isJadibotExpired()` dicek saat disconnect, padahal expiry baru tersimpan setelah `connection === 'open'` — selalu kebaca "tidak ada data" → dianggap expired~
2. Cek expired sekarang hanya jalan kalau sesi sudah pernah konek minimal sekali (`hasConnectedOnce`)
> Proses pairing tidak lagi gagal di tengah jalan karena dikira kedaluwarsa

*2. 🐛 .rvo2 Tidak Merespon di JadiBot*
_`.rvo2` jalan normal di bot utama, tapi diam saja di sesi jadibot._
1. ~`rvo2` tidak pernah dimasukkan ke daftar `loadedCommands` jadibot — langsung diabaikan sebelum sampai handler~
2. `rvo2` ditambahkan ke daftar `loadedCommands` jadibot (jalur pairing-code & QR)
> `.rvo2` sekarang merespon normal di jadibot

*3. 🐛 .delbot Tidak Merespon di JadiBot*
_Sama seperti kasus `.rvo2` — `.delbot` diam saja di sesi jadibot._
1. ~`delbot` tidak ada di `jadibotAllowedCommands` maupun `loadedCommands` jadibot~
2. `delbot` ditambahkan ke semua daftar yang diperlukan
> `.delbot` sekarang merespon normal di jadibot

*4. 🐛 .del di Grup Salah Deteksi "Bot Bukan Admin" (Bug LID)*
_`.del` tolak dengan pesan "Bot bukan admin", padahal bot sebenarnya admin._
1. ~Cek admin hanya cocokkan nomor telepon — WA sekarang sering kirim identitas format LID, bukan nomor, jadi cocokkan gagal~
2. ~Hasil cek yang salah langsung timpa cache → status admin rusak permanen sampai cache direset~
3. Bot sekarang dicocokkan lewat nomor telepon ATAU LID; kalau tidak ketemu, cache lama tidak ditimpa
> `.del` mendeteksi status admin bot dengan akurat, cache tidak rusak

*10. 🐛 .hd 1k/2k/3k/4x/max — Resize Tidak Jalan Sama Sekali (URL Format Salah)*
_Fitur resize quality level baru tidak menghasilkan apa-apa meski tidak error._
1. ~`resizeViaWeserv` kirim URL format `https%3A%2F%2F...` ke weserv.nl — weserv butuh format `ssl:host/path`, bukan `https://` yang di-encode biasa~
2. URL sekarang dikonversi dulu: `https://foo.com/img.jpg` → `ssl:foo.com/img.jpg` sebelum dikirim ke weserv
> Resize via weserv.nl sekarang benar-benar jalan untuk semua level

*11. 🐛 .hd — Flag &we Blokir Resize ke Resolusi Lebih Kecil*
_Resize dari AI output besar ke target kecil (mis. `.hd 1k`) tidak turun ke 1024px._
1. ~Flag `&we` (withoutEnlargement) dipasang di URL weserv — flag ini blokir SEMUA perubahan ukuran, naik maupun turun~
2. Flag `&we` dihapus; weserv sekarang bebas resize ke target width apapun
> `.hd 1k` pada gambar AI 2000px kini benar-benar turun ke ~1024px

*12. 🐛 .hd max — Resolusi Output Tidak Konsisten / Random*
_`.hd max` kadang hasilkan gambar 600px, kadang 1200px — tidak ada patokan._
1. ~`max` didefinisikan `width: null` → tidak ada resize → ukuran output sepenuhnya tergantung apa yang dikembalikan AI (tidak terprediksi)~
2. `max` sekarang disamakan dengan `4x` → `width: 4096` — resolusi tetap & konsisten
> `.hd max` selalu hasilkan gambar ~4096px, tidak random

❌ *ERROR FIX*
━━━━━━━━━━━━━━━━━━━━━━
*1. ❌ .upbot Selalu Gagal — Parameter Shadowing*
_Setiap `.upbot` dipanggil langsung error "is not a function"._
1. ~`handleUpbot` destrukturisasi `parseJadibotCommandQuery` dari parameter, padahal `message.js` tidak pernah kirim — nilainya `undefined` → crash~
2. Parameter dihapus dari destrukturisasi; fungsi dipanggil langsung dari scope file
> `.upbot` sekarang bisa dipakai — sebelumnya selalu crash

*2. ❌ JadiBot Stuck / Seluruh Bot Crash saat Restart*
_1 sesi jadibot yang error saat startup bisa mematikan seluruh proses bot._
1. ~`startJadibot()` dipanggil tanpa `.catch()` di 3 tempat — error jadi unhandled rejection~
2. ~Node.js 15+ langsung matikan proses saat ada unhandled rejection → bot restart, siklus crash berulang~
3. Ditambahkan `process.on('unhandledRejection')` global; ketiga pemanggilan `startJadibot()` sekarang dijaga `.catch()`
> Error di 1 sesi jadibot tidak lagi menyeret sesi lain atau mematikan seluruh bot
