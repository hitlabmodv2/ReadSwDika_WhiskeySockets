*1. 🔗 AntiLink — Bulk Toggle "off all" / "on all"*
_Sekarang owner bisa atur AntiLink di semua grup sekaligus, tanpa satu-satu._
1. Tambah perintah `.antilink off all` — nonaktifkan AntiLink di *semua grup terdaftar*, khusus owner
2. Tambah perintah `.antilink on all` — aktifkan AntiLink di *semua grup terdaftar*, khusus owner
3. Status langsung tampil otomatis setelah toggle, digabung jadi *satu pesan* _(tidak dobel)_

*2. 🔗 AntiLink — "add all" / "del all" via Balas Status*
_Saat membalas pesan status AntiLink, cukup ketik satu kata untuk terapkan ke semua grup:_
• `add all` — tambahkan seluruh grup ke daftar aktif
• `del all` — hapus seluruh grup dari daftar aktif

🔧 *BUG/ERROR FIX*

*1. 🎭 EmojiMode Log SW — Selalu Tampil "Default 🔵" Padahal Sudah Custom*
~Bug: di log AutoReadStoryWhatsApp, baris EmojiMode selalu tampil "Default 🔵" meskipun user sudah set mode Custom~
1. _Penyebab:_ `event.js` pakai `getJadibotEmojiMode()` yang baca dari `data_jadibot/<nomor>/emoji.json` — padahal bot utama simpan mode di `src/helper/emoji.json`
2. _Fix:_ diganti ke `getMode()` dari `emoji.js` yang baca file yang benar untuk bot utama
3. _Catatan:_ jadibot tidak terpengaruh — sudah benar sejak awal _(baca dari `data_jadibot/<nomor>/emoji.json`)_
> EmojiMode kini tampil akurat realtime sesuai mode aktif, tanpa restart bot

*2. 🔗 AntiLink "off all" Tidak Sinkron dengan config.json*
~Bug: setelah `.antilink off all`, `config.json` masih tampil `antiLink.enabled: true` walau tidak ada grup aktif tersisa~
1. _Fix:_ `off all` langsung set `antiLink.enabled: false` di `config.json` karena sudah pasti nol grup aktif
2. _Fix:_ `off` (single grup) ikut set `enabled: false` kalau ternyata itu grup aktif terakhir
3. _Fix:_ `del` / `del all` via balas status juga ikut set `enabled: false` saat hasilnya nol grup aktif
4. _Tetap seperti semula:_ `on all`, `on`, `add`, `add all` otomatis set `enabled: true`
> Status global AntiLink kini akurat realtime, selalu mencerminkan kondisi grup yang sebenarnya

*3. ❌ AntiTagSW Error "isAntiTagSWEnabled is not a function"*
~Bug: perintah `.antitagsw` selalu gagal dengan error tersebut~
1. _Penyebab:_ `message.js` tidak meneruskan beberapa dependency ke handler `.antitagsw`, di antaranya:
   • `isAntiTagSWEnabled`
   • `saveCekautoTimestamp`
   • `getAllAntiTagSWGroups`, `getWarnings`, `resetWarnings`, `kvGet`, dll
2. _Fix:_ semua parameter yang dibutuhkan sudah dilengkapi di pemanggilan handler
> `.antitagsw` kini berjalan normal tanpa error

*4. 📋 InformasiBotCommand Duplikat di Semua Perintah*
~Bug: setiap perintah (`.ram`, `.ping`, dll) selalu muncul dua kotak InformasiBotCommand di log konsol~
1. _Penyebab:_ `message.js` punya pemanggilan `_logCmdBox` global tepat setelah guard lolos (log pertama), lalu setiap handler juga memanggil `logCommand` di dalamnya (log kedua)
2. _Fix:_ hapus blok `_logCmdBox` global dari `message.js` — cukup log dari dalam handler masing-masing
> InformasiBotCommand kini tampil tepat satu kali per perintah

*5. 🖥️ MemoryMonitor Log — Tampilan Ringkas, Warna Jelas, Info Lengkap*
_Log konsol dirombak agar muat & terbaca di layar mobile panel Pterodactyl:_
1. Separator panjang (`━━━`) dihapus — hemat lebar layar
2. Header: `[MemoryMonitor] ✅ Normal cek ke-1 |` — teks cyan+bold, tidak abu-abu lagi

9. Label berwarna per kategori — *kuning* (waktu), *hijau* (memori bot/sys), *cyan* (detail proses), *magenta* (info sistem)
10. Label semua rata kiri 7 karakter — rapi berjejer di panel sempit
10. CPU load: *hijau* < 1.0, *kuning* 1.0–2.0, *merah* ≥ 2.0
