⚙️ *push.sh — File `.autopr` Otomatis Dibuat saat Login*
┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
*File:*
• `push.sh`
• `.gitignore`

*Perubahan:*
• Setelah login & token valid → file `.autopr` otomatis dibuat (kalau belum ada)
• `.autopr` berisi 3 setting: `enabled`, `base`, `draft` — bisa diedit kapan saja
• `auto_create_pr()` sekarang baca config dari `.autopr` sebelum buat PR
• `enabled=false` → auto PR dimatikan tanpa hapus kode
• `base=auto` → pakai `DEFAULT_BRANCH`; bisa diisi nama branch spesifik
• `draft=true` → PR dibuat sebagai Draft
• `.autopr` ditambahkan ke `.gitignore` — tidak ke-push ke GitHub

🔀 *push.sh — Auto Pull Request setelah Push ke Branch*
┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
*File:*
• `push.sh`

*Perubahan:*
• Tambah fungsi `auto_create_pr()` — otomatis buat PR via GitHub API setelah push berhasil
• Kalau PR sudah ada di branch itu → notif "PR diupdate" + link PR lama
• Kalau belum ada → buat PR baru + notif Telegram dengan tombol _Buka PR_ dan _Merge PR_
• Kalau push ke `DEFAULT_BRANCH` sendiri → skip otomatis (tidak perlu PR)
• Diterapkan ke 3 skenario push: _normal_, _graft_, _force_
