✨ *FITUR BARU*

*1. 🔤 Font Untik —* `.font`
_Ubah teks biasa jadi berbagai gaya font unik via tombol pilihan interaktif_
- Cara pakai: `.font [teks]`
- Bot kirim button single select → pilih gaya → hasil langsung dikirim
- Gaya tersedia: bold, italic, gothic, bubble, dan lainnya

*2. 🎞️ Anime GIF —* `.animegif` _/_ `.animgif` _/_ `.gifanime`
_Cari dan kirim GIF anime dari Tenor langsung ke chat_
- Cara pakai: `.animegif [kata kunci]`
- Contoh: `.animegif naruto`, `.animegif one piece fight`

*3. 🔥 Alqanime — Monitor "Lagi Hangat Saat Ini"*
_Bot kini pantau section "Lagi Hangat Saat Ini" di alqanime.net secara realtime_
- Saat ada anime baru masuk hot list → bot otomatis kirim notif *terpisah* ke semua GC aktif
- Format notif: `🔥 LAGI HANGAT — ALQANIME!` + daftar baru masuk + semua hot list saat ini
- Tidak ada request ganda — data diambil dari 1x fetch homepage bersamaan cek episode baru
> Aktif otomatis jika `.alqanimenotif on` sudah diaktifkan di GC

*4. 📨 JPM — Kirim Pesan Massal ke GC —* `.jpm`
_Kirim pesan teks/media ke semua GC atau satu GC tertentu, dengan delay otomatis dan progress realtime_
- *Cara pakai (pilih GC via menu):* `.jpm pesan | delay`
  → Bot tampilkan button pilih GC, klik → kirim ke GC itu saja
- *Cara pakai (ke satu GC):* `.jpm GID >> pesan | delay`
  → Langsung kirim ke GC dengan ID tersebut
- *Cara pakai (ke semua GC):* `.jpm << pesan | delay`
  → Kirim ke semua GC yang bot ikuti sekaligus
- Mendukung *teks* maupun *media* (gambar/video) — reply media saat pakai command
- Progress bar realtime (edit pesan otomatis saat proses berjalan)
- Delay minimal 3 detik/GC, maksimal 60 detik
- Bisa dihentikan kapan saja dengan `.jpmstop`
> Owner only

*5. 📋 JPM List —* `.jpmlist`
_Lihat daftar semua GC yang sedang diikuti bot, lengkap dengan nomor urut, nama GC, dan JID_
- Format: nomor | nama GC | JID
- Berguna untuk dapat GID yang dipakai di `.jpm GID >> pesan | delay`
> Owner only

*6. 📤 Push Kontak GC —* `.pushkontakgc`
_Kirim pesan teks/media langsung ke semua member di dalam satu GC, satu per satu dengan delay_
- *Cara pakai (teks):* `.pushkontakgc GID | pesan | delay`
- *Cara pakai (media):* reply gambar/video → `.pushkontakgc GID | caption | delay`
- Progress bar realtime (edit pesan otomatis saat proses berjalan)
- Delay minimal 3 detik, maksimal 10 detik per member
- Bisa dihentikan kapan saja dengan `.pushkontakgcstop` atau `.pkgstop`
- Guard aktif: jika proses masih berjalan → command baru ditolak otomatis
> Owner only

🔧 *BUG/ERROR FIX*
━━━━━━━━━━━━━━━━━━━━━━
*1. 🎵 Musikai/Musikai2 — Mode Instrumental Sering Muncul*
- ~Bug: mode Instrumental muncul terlalu sering padahal user tidak memilihnya~
- Penyebab: probabilitas Instrumental 55–35%, terlalu tinggi
- Fix: diturunkan ke *10%* — kini *90% Vokal* secara default
> Berlaku untuk `.musikai random` & `.musikai2 random`

*2. 👋 Welcome/Goodbye — Spam Pesan Error ke Grup*
- ~Bug: bot spam kirim pesan error ke grup padahal tidak ada yang pakai command~
- Penyebab: mode `allowNoPrefix` aktif → pesan sistem terbaca sebagai command
- Fix: guard ditambahkan — jika tidak ada prefix & arg bukan `on`/`off` → diam
> Berlaku untuk `.welcome`, `.goodbye`, `.welgod`

*3. 🎮 AN1 Game — Kini Work di Grup*
- ~Bug: `.an1game` error / tidak berfungsi saat dipakai di dalam grup~
- Fix: diperbaiki, kini work normal di grup maupun private chat
- Fungsi: cari game Android modded/premium gratis dari an1.com
> Cara pakai: `.an1game [nama game]`

*4. 🤖 WilyAI — Bug Analisis Stiker/Gambar*
- ~Bug: WilyAI error / tidak merespons saat user kirim stiker atau gambar~
- Penyebab: buffer stiker tidak diproses dengan benar sebelum dikirim ke Gemini Vision
- Fix: konversi buffer & mime type diperbaiki di autosimi + prompt stiker diperbarui
> Berlaku untuk auto-reply stiker maupun command `.wily` dengan attachment

*5. 🤖 WilyAI Grup — Memori Tercampur Antar Peserta*
- ~Bug: di grup, history chat WilyAI tercampur antara satu user dengan user lain~
- Penyebab: session key pakai `sender_groupJid` (unik per user) bukan JID grup
- Fix: session key diubah ke `m.from` (JID grup) → semua peserta grup berbagi satu sesi
> WilyAI di grup kini sadar percakapan multi-peserta secara benar

*6. 🔗 Anti-Link — Bot Diam Saat Bukan Admin*
- ~Bug: saat bot bukan admin di grup, bot sama sekali tidak merespons ketika ada link masuk~
- Penyebab: kode langsung `return` (silent skip) tanpa kirim notif apapun
- Fix: bot kini tetap kirim peringatan di grup meskipun bukan admin
> Admin grup langsung tahu ada link masuk & bot perlu dijadikan admin

*7. 🔗 Anti-Link — Nama Pengirim Tidak Tampil (Akun Privat)*
- ~Bug: akun privat (LID) tampil sebagai "(akun privat)" — nama asli tidak terlihat~
- Penyebab: kode tidak mengambil `pushName` dari objek pesan
- Fix: sekarang pakai `message.pushName` → nama display tampil realtime
> Jika pushName tidak tersedia, fallback ke _akun privat_
