🔧 *BUG/ERROR FIX*

*1. 🎭 EmojiMode Log SW — Selalu Tampil "Default 🔵" Padahal Sudah Custom*
- ~Bug: di log AutoReadStoryWhatsApp, baris EmojiMode selalu tampil "Default 🔵" meskipun user sudah set mode Custom~
- Penyebab: `event.js` pakai `getJadibotEmojiMode()` yang baca dari `data_jadibot/<nomor>/emoji.json` — padahal bot utama simpan mode di `src/helper/emoji.json`
- Fix: diganti ke `getMode()` dari `emoji.js` yang baca file yang benar untuk bot utama
- Jadibot tidak terpengaruh — sudah benar sejak awal (baca dari `data_jadibot/<nomor>/emoji.json`)
> EmojiMode kini tampil akurat realtime sesuai mode aktif, tanpa restart bot

*2. 🔗 AntiLink "off all" Tidak Sinkron dengan config.json*
- ~Bug: setelah `.antilink off all`, `config.json` masih tampil `antiLink.enabled: true` walau tidak ada grup aktif tersisa~
- Fix: `off all`, `off` (single, jika jadi grup aktif terakhir), dan `del`/`del all` via balas status sekarang otomatis set `antiLink.enabled: false` di `config.json` saat nol grup aktif tersisa
- `on all`, `on`, `add`, `add all` tetap otomatis set `enabled: true` seperti sebelumnya
> Status global AntiLink kini akurat realtime, selalu mencerminkan kondisi grup yang sebenarnya

*3. ❌ AntiTagSW Error "isAntiTagSWEnabled is not a function"*
- ~Bug: perintah `.antitagsw` selalu gagal dengan error tersebut~
- Penyebab: `message.js` tidak meneruskan `isAntiTagSWEnabled` dan beberapa dependency lain (`saveCekautoTimestamp`, `getAllAntiTagSWGroups`, `getWarnings`, `resetWarnings`, `kvGet`, dll) ke handler `.antitagsw`
- Fix: semua parameter yang dibutuhkan sudah dilengkapi di pemanggilan handler
> `.antitagsw` kini berjalan normal tanpa error
