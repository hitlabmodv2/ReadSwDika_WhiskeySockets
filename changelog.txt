> NO.1 🎵 *Musikai/Musikai2 — Mode Instrumental Sering Muncul*
> Bug: mode Instrumental muncul terlalu sering padahal user tidak memilihnya
> Penyebab: getRandomPreset() punya probabilitas 55% Instrumental, aiRandomPreset() 35%
> Fix: probabilitas diturunkan ke 10% — kini 90% Vokal secara default
> Berlaku untuk: .musikai random & .musikai2 random

> NO.2 👋 *Welcome/Goodbye — Spam Pesan Error ke Grup*
> Bug: bot spam kirim "❌ Fitur Welcome/Goodbye dinonaktifkan secara global" ke grup
> Penyebab: mode allowNoPrefix aktif → pesan bot lain/sistem seperti "welcome to the group"
>           terbaca sebagai command .welcome → handler jalan → error dikirim ke grup
> Fix: guard ditambahkan — jika tidak ada prefix (.) dan arg bukan on/off → diam saja
> Berlaku untuk: .welcome, .goodbye, .welgod

> NO.3 🎮 *AN1 Game — .an1game Kini Work di Grup*
> Bug: fitur .an1game sebelumnya error / tidak berfungsi saat dipakai di grup
> Fix: diperbaiki — .an1game kini work normal di grup maupun private chat
> Fungsi: cari game Android modded/premium gratis dari an1.com
> Cara pakai: .an1game [nama game]
