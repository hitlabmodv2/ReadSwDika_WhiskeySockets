> Setiap userjadibot punya SwTrack sendiri — tidak campur dengan data jadibot lain

> Hanya perintah yang benar-benar dieksekusi yang ditampilkan — tidak ada log yang tidak perlu
> Notif cmd userjadibot tampil terpisah dari bot utama — mudah dibedakan di log
> Log lebih sedikit, lebih mudah dibaca, dan tetap informatif

🚀 *IMPROVEMENT*
━━━━━━━━━━━━━━━━━━━━━━
> 🗂️ *Folder src/scrape — Dirapikan Per Kategori*
> File scraper yang sebelumnya campur kini dipisah ke folder sesuai fungsinya
> ai/ → semua scraper AI (gemini, sparkpix, imageEdit, dll)
> download/ → semua downloader (yt, ig, tt, fb, twitter, reddit, allunduh, dll)
> anime/ → scraper konten anime (alqanime, animasu, pixiv, nhentai, dll)
> music/ → scraper musik (chatmusic, genius, whatsmusik, dll)
> news/ → scraper berita (malnews, tvonenews)
> tools/ → scraper utilitas (screenshot, cuaca, speedtest, dll)
> system/ → file sistem bot (welcomeCard, shutdown)

> 🧹 *Session Bot Utama — Disatukan Jadi 1 File*
> Sebelumnya sesi bot utama tersebar di banyak file dalam satu folder
> Kini semua data sesi bot utama disatukan ke dalam 1 file JSON saja: `sessions/{nama_sesi}.json`
> Lebih ringan, lebih rapi, tidak ada file sisa yang menumpuk

> 🔀 *Session Userjadibot — 1 File Per Nomor, Benar-Benar Terpisah*
> Setiap userjadibot kini punya 1 file sesi sendiri: `jadibot/{nomor}.json`
> Tidak ada campur-aduk antara sesi bot utama dan sesi masing-masing userjadibot
> Tidak ada bentrok — setiap jadibot berjalan independen di filenya sendiri
> Sesi jadibot otomatis dihapus saat masa aktif habis, tidak ada sisa file yang mengganggu
