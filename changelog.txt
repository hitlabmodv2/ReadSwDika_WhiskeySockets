> NO.2 🎨 *Sistem Mode Emoji Bot Utama — Custom vs Default (Tidak Bentrok)*
> Bot utama kini punya sistem mode emoji terpisah dari userjadibot
> Mode Custom: pakai emoji kustom kamu sendiri (tersimpan di customEmojis[])
> Mode Default: pakai pool 1900 emoji bawaan (tersimpan di emojis[])
> Kedua mode disimpan di satu file (src/helper/emoji.json) di field terpisah — tidak saling overwrite
> Data userjadibot tersimpan di folder masing-masing (data_jadibot/xxx/) — tidak bentrok sama sekali
> Command yang tersedia:
> ▸ .emojicustom → aktifkan mode custom
> ▸ .emojidefault → balik ke pool 1900 default
> ▸ .emojiclear → reset emoji kustom ke seed awal
> ▸ .emojiadd / .emojidel → tambah/hapus emoji di mode aktif
> ▸ .emojilist → lihat daftar & mode aktif sekarang

> NO.3 📋 *Info Mode Aktif di Respons Emoji Command*
> Seluruh respons command emoji kini tampilkan info mode aktif secara realtime
> Berlaku di: .emojiadd, .emojidel, .emojilist — untuk bot utama & userjadibot
> Contoh: ⚙️ Mode: 🎨 Custom (kustom kamu) atau 🌐 Default (pool 1900 emoji)
> Tujuan: langsung tahu emoji masuk/dihapus dari laci mana tanpa perlu tebak-tebakan
