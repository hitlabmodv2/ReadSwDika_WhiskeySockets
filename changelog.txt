> NO.2 🎮 *Auto Notif Game MOD — .anigame / .gamean1 / .an1game*
> Bot otomatis kirim notif ke grup saat ada game MOD baru di AN1.COM
> Cek setiap 10 menit secara otomatis sejak bot start
> Sumber: an1.com/games/
> *Perintah owner (di grup):*
> .anigame on — aktifkan notif di grup ini
> .anigame off — nonaktifkan notif di grup ini
> .anigame test — kirim test notif ke grup ini
> .anigame test grup — kirim test ke semua grup aktif
> .anigame status — lihat daftar semua grup aktif/nonaktif
> *Perintah semua user:*
> .anigame list — lihat daftar game terbaru + thumbnail
> .anigame [nama game] — cari game, contoh: .anigame minecraft
> Setting tersimpan per-grup di config.json — tidak hilang saat restart

🔧 *BUG FIX*

> NO.1 ⚡ *Koneksi Bot Utama & Userjadibot — 2x Lebih Cepat dari Sebelumnya*
> Bug: sesi menyimpan banyak file terpisah (useMultiFileAuthState) → baca/tulis lambat saat connect
> Fix: migrasi ke useSingleFileAuthState — semua data (creds, keys, contacts, groups, settings)
>   dipadatkan jadi 1 file JSON per sesi (bot utama & setiap userjadibot)
> Tulis file pakai pola atomic (.tmp → rename) — tidak corrupt meski bot crash di tengah tulis
> Berlaku untuk: bot utama, userjadibot, dan proses browser switch
> Hasil: koneksi terasa 2x lebih cepat, tidak ada lagi spam file di folder sessions

> NO.2 ⚙️ *PM2 di Panel Pterodactyl — Tidak Bisa Jalan (ecosystem.config.cjs)*
> Bug: PM2 gagal start di panel Pterodactyl karena config tidak kompatibel
> Fix: ecosystem.config.cjs diperbaiki — path absolut, fork mode, heap size eksplisit
> Logging lengkap: pm2-out.log, pm2-error.log, pm2-combined.log
> Auto restart jika crash (max 10x), restart jika RAM > 500MB
> *Cara pakai di panel Pterodactyl:*
> 1️⃣ Jalankan npm i dulu untuk install semua modul
> 2️⃣ Di panel → Startup → ubah Startup Command jadi:
>     pm2 delete wily-bot 2>/dev/null; pm2 start ecosystem.config.cjs && pm2 monit
