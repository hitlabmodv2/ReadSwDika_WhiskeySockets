*1. 🎌 .nekopoinotif — Button Quick Edit Kategori 2 Layar*
_Setelah aktifkan/matikan notif, langsung muncul tombol kontekstual. Edit kategori tinggal tap, tidak perlu ketik perintah panjang._
1. Setelah *aktifkan* → tombol: `❌ Matikan GC Ini` · `✏️ Edit Kategori` · `📋 Lihat GC Aktif`
2. Setelah *matikan* → tombol: `✅ Aktifkan GC Ini` · `✏️ Edit Kategori` · `📋 Lihat GC Aktif`
3. Tap `✏️ Edit Kategori` → layar khusus dengan 3 tombol toggle: `✅/❌ 🎌 Hentai` · `✅/❌ 🎥 2D Anim` · `✅/❌ 🧊 3D Hentai`
4. Label tombol kategori langsung tampilkan status aktif/nonaktif saat ini — tap untuk toggle
> Berlaku konsisten di semua jalur: command `.nekopoinotif on/off` maupun tap button dari menu

*2. 🔙 .nekopoinotif — Tombol Kembali di Layar Edit Kategori*
_Di layar Edit Kategori, ada tombol keempat untuk balik ke layar ON/OFF tanpa perlu ketik ulang._
1. Layar Edit Kategori sekarang punya 4 tombol: `✅/❌ Hentai` · `✅/❌ 2D Anim` · `✅/❌ 3D Hentai` · `🔙 Kembali`
2. Tap `🔙 Kembali` → bot cek status grup saat ini → tampilkan layar ON/OFF yang sesuai (Aktifkan atau Matikan)
3. Bisa navigasi bolak-balik: ON/OFF → Edit Kategori → Kembali → Edit Kategori → dst
> Tidak perlu ketik `.nekopoinotif` ulang setelah edit kategori
